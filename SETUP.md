# iSchool Senior Advising Chatbot

A Langchain-based chatbot designed to help San José State University iSchool students with advising questions. Now with **RAG (Retrieval Augmented Generation)** support for document-aware responses!

## Features

- **Multi-LLM Support**: Test with OpenAI, Anthropic Claude, or HuggingFace models
- **RAG Integration**: Retrieve relevant documents to provide context-aware answers
- **Knowledge Base**: Hardcoded answers for common trivial questions (instant responses)
- **Modular Architecture**: Easy to swap LLM providers and add new features
- **Conversation History**: Tracks conversation context
- **CLI Interface**: Simple command-line interface for testing

## System Architecture

```
User Input
    ↓
┌─────────────────────────────────────┐
│ Knowledge Base (Hardcoded Answers)   │ ← Fast lookup for common questions
└────────────┬────────────────────────┘
             ↓ (if no match)
┌──────────────────────────────────────┐
│ Document Retrieval (Vector Store)     │ ← Semantic search in advising docs
└────────────┬───────────────────────────┘
             ↓
┌──────────────────────────────────────┐
│ LLM with Context (OpenAI/Anthropic)   │ ← Generate informed response
└────────────┬───────────────────────────┘
             ↓
          Response
```

## Supported LLM Providers

1. **OpenAI** (GPT-3.5-turbo, GPT-4) - Recommended
2. **Anthropic Claude** (Claude-2)
3. **HuggingFace** (Open-source models like Llama-2)

## Setup

### Prerequisites
- Python 3.8+
- Virtual environment (recommended)

### Installation

1. **Clone the repository**
```bash
git clone <repo-url>
cd group-project-team-22
```

2. **Create and activate virtual environment**
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

3. **Install dependencies**
```bash
pip install -r requirements.txt
```

4. **Configure environment variables**
```bash
# Copy the example configuration
cp .env.example .env

# Edit .env with your API keys
```

### Configuration

Edit `.env` file with your API credentials:

```env
# OpenAI Configuration (Recommended for testing)
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-3.5-turbo

# Anthropic Configuration
ANTHROPIC_API_KEY=your_anthropic_api_key_here
ANTHROPIC_MODEL=claude-2

# HuggingFace Configuration
HUGGINGFACE_API_KEY=your_huggingface_api_key_here
HUGGINGFACE_MODEL=meta-llama/Llama-2-7b-hf

# Application Configuration
DEFAULT_LLM_PROVIDER=openai
```

## Usage

### Running the RAG Chatbot CLI

```bash
cd src
python main.py
```

**Available Commands:**
- Type your question and press Enter
- `exit` - Quit the chatbot
- `clear` - Clear conversation history
- `docs` - Load and process advising documents
- `questions` - Show all hardcoded questions
- `help` - Show help menu

### Example Interactions

#### Hardcoded Question (Instant Response)
```
You: What do I need to graduate?
Assistant: [Instant response from knowledge base]
[Source: Knowledge Base]
```

#### RAG Question (Document-Enhanced Response)
```
You: Can you explain the capstone project requirements?
Assistant: [Response using document context and LLM]
[Source: Document Retrieval + LLM] (2 documents)
```

#### Complex Question (LLM Only)
```
You: How should I plan my course schedule?
Assistant: [Response generated by LLM]
[Source: LLM]
```

### Adding Your Advising Documents

1. **Place documents in** `./data/advising_docs/`
   - Supports `.txt` and `.pdf` files
   - Can have subdirectories

2. **In the chatbot, run:**
   ```
   docs
   ```

3. **Documents are processed and indexed** using vector embeddings

### Using the Chatbot Programmatically

```python
from rag_chatbot import RAGAdvisingChatbot

# Initialize with default provider
chatbot = RAGAdvisingChatbot()

# Or with specific provider
chatbot = RAGAdvisingChatbot(llm_provider="openai")

# Load documents
chatbot.process_documents("./data/advising_docs")

# Send a message
result = chatbot.chat("What courses do I need?")

# Response metadata
print(result["response"])        # The actual response
print(result["source"])         # "knowledge_base", "rag", or "llm"
print(result["retrieved_docs"]) # Documents used for context
```

## How RAG Works

### Step 1: Knowledge Base Lookup
- User question is checked against hardcoded Q&A
- Instant response if matched
- Uses keyword matching with confidence scoring

### Step 2: Document Retrieval
- Question is converted to embeddings
- Vector similarity search in stored documents
- Top 3 most relevant documents retrieved

### Step 3: LLM Generation
- Retrieved documents provide context
- LLM generates answer grounded in documents
- Falls back to general LLM knowledge if no docs found

## Troubleshooting

**No documents found error:**
```bash
# Create sample documents
cd src
python -c "from document_processor import setup_sample_docs; setup_sample_docs()"
```

**Vector store errors:**
- Delete `data/chroma` directory and recreate
- Reinstall `chromadb`: `pip install --upgrade chromadb`

**LLM API errors:**
- Verify API keys in `.env`
- Check API key validity on provider's dashboard
- Ensure sufficient API quota
